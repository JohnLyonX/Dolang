# Epic E01：标准库基础设施完善（非 HTTP）

## 背景

Dolang 解释器已具备基础的 native 模块（str、math、json、fs、env），
但多个模块存在功能空洞，导致使用者无法用纯 .dol 代码完成常见任务，
必须绕过解释器或依赖外部工具。

本 Epic 聚焦于**补齐现有模块的 native 层**，不涉及 HTTP 客户端（单独 Epic）。

## 目标

- fs 可以做完整的目录操作（创建、列出、删除、复制、移动）
- math 可以做完整的数值计算（反三角、对数、随机数）
- json 可以做完整的对象操作（增删改查、美化输出）
- list 可以做排序、查找、切片
- env 可以写入和枚举环境变量
- io 可以读取用户输入和格式化输出

## 不在范围内

- HTTP 客户端（`std.http`）— 单独 Epic
- Map 高级操作 — 可在后续 Epic 中跟进
- Lambda / 高阶函数 — 依赖语言层特性，不在本 Epic

## 验收标准

所有 Issue 的 native 函数实现后，对应的纯 .dol stdlib 文件可以不带 workaround 地实现，
并通过 `cargo test` 全部测试。
