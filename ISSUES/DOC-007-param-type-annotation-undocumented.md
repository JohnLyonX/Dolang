# DOC-007: 函数参数类型注解语法在所有章节中均未涉及

**优先级：** P1
**影响章节：** `docs/guide/07-functions.md`、`docs/guide/09-gradual-typing.md`

## 问题描述

第 7 章（函数）和第 9 章（渐进类型）都回避了函数参数类型注解的问题。第 7 章明确说"先按无参数类型注解来教"，第 9 章只讲了变量声明和返回类型的注解。

这留下了一个空洞：

- 参数类型注解语法是否存在（如 `$fn greet(name: Str) -> Str`）？
- 如果存在，写法是什么？
- 如果不存在，为什么返回类型可以注解但参数不行？
- 函数签名里有没有类型信息会影响 IDE/LSP 的提示能力吗？

这是用户在掌握基础类型系统后必然会遇到的问题。

## 期望改进

**方案 A（如果当前不支持参数类型注解）：**

在 `07-functions.md` 中明确说明：
> 当前版本的参数不支持类型注解。如需约束入参类型，建议在函数体内用 `.type()` 手动检查或使用 `$try/$catch`。

**方案 B（如果已支持）：**

在 `09-gradual-typing.md` 补充完整示例：
```dol
$fn add(a: Int, b: Int) -> Int {
    $# a + b;
}
```
并说明参数类型检查的时机（调用时还是运行时）。

## 验证方法

尝试运行带参数类型注解的函数，观察 parser 是否接受，runtime 是否做检查。
