Core Philosophy

      
Built on six symbols,
mastered in minutes

    


    

      

        
§ 01 · Syntax

        
Minimal Symbol Grammar

        
Dolang's core philosophy centers on a few distinct symbols like $  $@  $>>  =  $fn  $#.
          No complex boilerplate to endure. You can learn the entire grammar in five minutes.

      

      

        
§ 02 · Variables

        
Variable Shadowing

        
Re-declare any variable with $ to shadow it
          entirely — even across types. A numeric variable may become a string without ceremony. Flexibility, by design.
        

      

      

        
§ 03 · Constants

        
Constant Protection

        
Declare immutable values with $@ and the
          interpreter guarantees they remain untouched. Any reassignment attempt yields a clear, immediate error — no
          silent corruption.

      

      

        
§ 04 · Data Types

        
Collections & Types

        
Out of the box support for runtime dynamic typing, Lists, Maps, Strings, and Numbers.
          Mix them seamlessly. Iterate with `for-in` loops or modify with built-in methods instantaneously.

      

      

        
§ 05 · REPL

        
Professional REPL

        
A fully-featured interactive shell with command history navigation, cursor editing,
          Ctrl+A/E line jumps, and graceful interrupt handling. It even supports multi-line functional declarations
          natively.

      

      

        
§ 06 · Engine

        
Rust-Powered Core

        
The interpreter is written entirely in Rust — memory safe, garbage-collector free, and
          natively performant. Compile in seconds on macOS/Linux. Ready to be deployed as a fast script engine.

Language Reference

        
All six symbols,
catalogued

        

          The complete grammar of DoLang fits in a single table. This is not a limitation — it is the design. Every
          language feature is discoverable in moments, memorable in minutes, and internalized in an afternoon.
        

      


      

        

          
            

              Symbol
              Function
            

          
          
            

              $
              Declare a mutable variable
            

            

              $@
              Declare an immutable constant
            

            

              $fn
              Declare a function
            

            

              $#
              Return value from function
            

            

              $>>
              Print expression to stdout
            

            

              =
              Assign a value to a variable
            

            

              ;
              Statement terminator (required)
