# DOC-017: 第 16 章未说明路由冲突的行为

**优先级：** P3
**影响章节：** `docs/guide/16-http-organization.md`

## 问题描述

使用 `$HTTP { }` 路由块和 `.link()` 组合挂载路由时，用户可能不小心注册了相同路径的两个 handler。文档没有说明这种情况的行为：

- 后注册的覆盖先注册的？
- 还是启动时直接报错？
- 还是运行时第一个 handler 生效，第二个静默忽略？

这在多人协作的模块化项目里很容易发生。

## 期望改进

在 `16-http-organization.md` 补充路由冲突说明：

```dol
$GET("/health") health_v1() -> String { $# "v1"; }
$GET("/health") health_v2() -> String { $# "v2"; }
// 行为是？
```

说明当前的冲突处理策略（最后注册优先？还是报错？），帮助用户在调试路由冲突问题时有明确预期。
