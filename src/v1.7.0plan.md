# Dolang v1.7.0 重构计划

> **目标**：解耦内置方法实现，引入类型安全的值表示，使代码库具备长期可扩展性。

---

## 背景与问题

当前 `src/interpreter/eval.rs` 承担了过重的职责，约 700 行代码同时处理表达式求值和所有类型的内置方法实现。根本原因是两个相互耦合的设计缺陷：

**缺陷一：用字符串前缀模拟类型系统**

```rust
// 现状 — 脆弱，无编译期保证
if obj_val.starts_with("__LST__:") { ... }
if obj_val.starts_with("__MAP__:") { ... }
```

类型判断依赖字符串比较，既无法利用 Rust 编译器的穷举检查，也导致类型逻辑无法与方法逻辑分离。

**缺陷二：方法实现无法物理分离**

因为类型判断与方法实现耦合在同一套 if-else 链中，所有类型的方法只能堆在同一个文件里，随语言功能增长持续膨胀。

#### 步骤 2.1 — 新建 `value.rs`

```rust
// src/interpreter/value.rs

use indexmap::IndexMap;
use std::fmt;

/// Dolang 运行时值的类型安全表示
///
/// 设计决策：
/// - Char 内部归入 Str（与 Dolang 文档一致："字符类型在内部也以字符串形式存储"）
/// - Null 表示无返回值函数的结果（$fn greet() { ... } 无 $# 语句时）
/// - Function 表示匿名函数作为一等公民存储在变量中的情况
#[derive(Debug, Clone)]
pub enum DolangValue {
    Int(i64),
    Float(f64),
    Str(String),
    Bool(bool),
    List(Vec<DolangValue>),
    Map(IndexMap<String, DolangValue>),
    Function {
        params: Vec<String>,
        body: Vec<Stmt>,            // 复用现有 AST 节点
        return_type: Option<String>,
    },
    Null,
}
```

**设计说明**：

1. **为什么需要 `Null`**
   Dolang 支持无返回值函数（如 `$fn greet(name) { $>> "Hello " + name; }`），
   这类函数执行后需要一个值来表示"什么也没返回"。
   没有 `Null`，调用方无法区分"函数忘了返回"和"返回了空字符串"。

2. **为什么需要 `Function`**
   Dolang 支持匿名函数赋值给变量 `$result = $fn(x, y) -> Int { $# x + y; };`，
   变量 `result` 的运行时值就是一个函数对象，环境（env）必须能存储它。

3. **为什么没有 `Char` variant**
   Dolang 文档明确："字符类型在内部也以字符串形式存储"，因此 `'a'` 在运行时统一表示为 `Str("a".to_string())`，无需独立 variant。

4. **为什么不 derive `PartialEq`**
   `f64` 的 `PartialEq` 存在 NaN 陷阱（`NaN != NaN`），`Function` 语义上也不可比较。
   需要手动实现，明确各类型的相等语义：

```rust
impl PartialEq for DolangValue {
    fn eq(&self, other: &Self) -> bool {
        match (self, other) {
            (Self::Int(a), Self::Int(b))     => a == b,
            (Self::Float(a), Self::Float(b)) => {
                // 处理 NaN：Dolang 语义中 NaN == NaN → false
                a == b
            }
            (Self::Str(a), Self::Str(b))     => a == b,
            (Self::Bool(a), Self::Bool(b))   => a == b,
            (Self::Null, Self::Null)         => true,
            // List / Map 递归比较
            (Self::List(a), Self::List(b))   => a == b,
            (Self::Map(a), Self::Map(b))     => a == b,
            // Function 不可比较
            (Self::Function { .. }, _)       => false,
            _ => false,
        }
    }
}
```

5. **实现 `Display` trait 而非自定义 `display()` 方法**

```rust
/// 遵循 Rust 惯例：实现 std::fmt::Display
/// 这样可以直接用 format!("{}", value)、println!("{}", value)、value.to_string()
impl fmt::Display for DolangValue {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            Self::Int(n)    => write!(f, "{}", n),
            Self::Float(n)  => write!(f, "{}", n),
            Self::Str(s)    => write!(f, "{}", s),
            Self::Bool(b)   => write!(f, "{}", b),
            Self::Null      => write!(f, "null"),
            Self::List(items) => {
                write!(f, "[")?;
                for (i, item) in items.iter().enumerate() {
                    if i > 0 { write!(f, ", ")?; }
                    write!(f, "{}", item)?;
                }
                write!(f, "]")
            }
            Self::Map(map) => {
                write!(f, "{{")?;
                for (i, (k, v)) in map.iter().enumerate() {
                    if i > 0 { write!(f, ", ")?; }
                    write!(f, "{}: {}", k, v)?;
                }
                write!(f, "}}")
            }
            Self::Function { params, .. } => {
                write!(f, "<fn({})>", params.join(", "))
            }
        }
    }
}
```

6. **运行时类型名**

```rust
impl DolangValue {
    /// 用于 .type() 方法返回值
    pub fn type_name(&self) -> &'static str {
        match self {
            Self::Int(_)         => "Int",
            Self::Float(_)       => "Float",
            Self::Str(_)         => "String",
            Self::Bool(_)        => "Bool",
            Self::List(_)        => "List",
            Self::Map(_)         => "Map",
            Self::Function { .. } => "Function",
            Self::Null           => "Null",
        }
    }

    /// Phase 2 过渡期：从旧版字符串存储格式解析为 DolangValue
    /// Phase 2 稳定后删除此方法
    pub fn parse_legacy(s: &str) -> Self { ... }

    /// Phase 2 过渡期：序列化回旧版字符串存储格式
    /// Phase 2 稳定后删除此方法
    pub fn to_legacy(&self) -> String { ... }
}
```

> **命名说明**：使用 `parse_legacy` / `to_legacy` 而非 `from_raw` / `to_raw`。
> 在 Rust 中 `from_raw` / `into_raw` 惯例用于 unsafe 裸指针操作（如 `Box::from_raw`），
> 此处的语义是"旧格式兼容转换"，用 `legacy` 明确意图且避免歧义。

#### 步骤 2.3 — 更新各 `builtins/*.rs` 签名

将 Phase 1 中的临时 `&str` 签名升级为 `&DolangValue`。

可变方法（`push`, `pop`, `reverse`, `remove`）和不可变方法需要不同签名：

```rust
/// 不可变方法：len, contains, join, upper, lower, keys, values, type ...
pub fn call(
    receiver: &DolangValue,
    method: &str,
    args: &[DolangValue],
) -> Result<DolangValue, DolangError>

/// 可变方法：push, pop, reverse, remove
/// 需要 &mut 来就地修改 receiver
pub fn call_mut(
    receiver: &mut DolangValue,
    method: &str,
    args: &[DolangValue],
) -> Result<DolangValue, DolangError>
```

各类型文件中区分处理：

```rust
// builtins/list.rs

/// 不可变方法
pub fn call(receiver: &DolangValue, method: &str, args: &[DolangValue])
    -> Result<DolangValue, DolangError>
{
    let items = match receiver {
        DolangValue::List(items) => items,
        _ => unreachable!(),
    };
    match method {
        "len"      => Ok(DolangValue::Int(items.len() as i64)),
        "contains" => contains(items, args),
        "join"     => join(items, args),
        "type"     => Ok(DolangValue::Str("List".to_string())),
        _ => Err(DolangError::Runtime(format!("List has no method '{}'", method))),
    }
}

/// 可变方法
pub fn call_mut(receiver: &mut DolangValue, method: &str, args: &[DolangValue])
    -> Result<DolangValue, DolangError>
{
    let items = match receiver {
        DolangValue::List(items) => items,
        _ => unreachable!(),
    };
    match method {
        "push"    => { items.push(args[0].clone()); Ok(receiver.clone()) }
        "pop"     => items.pop().ok_or_else(|| DolangError::Runtime("pop on empty list".into())),
        "reverse" => { items.reverse(); Ok(receiver.clone()) }
        _ => Err(DolangError::Runtime(format!("List has no mutable method '{}'", method))),
    }
}
```

#### 步骤 2.4 — 更新 `builtins/mod.rs` 分发

```rust
/// 判断方法是否需要可变访问
fn is_mutating(method: &str) -> bool {
    matches!(method, "push" | "pop" | "reverse" | "remove")
}

/// 不可变方法分发
pub fn dispatch(
    receiver: &DolangValue,
    method: &str,
    args: &[DolangValue],
) -> Result<DolangValue, DolangError> {
    match receiver {
        DolangValue::List(_)                        => list::call(receiver, method, args),
        DolangValue::Map(_)                         => map::call(receiver, method, args),
        DolangValue::Str(_)                         => str_methods::call(receiver, method, args),
        DolangValue::Int(_) | DolangValue::Float(_) => number::call(receiver, method, args),
        DolangValue::Bool(_)                        => bool_methods::call(receiver, method, args),
        DolangValue::Function { .. }                => Err(DolangError::Runtime(
            format!("Function has no method '{}'", method)
        )),
        DolangValue::Null                           => Err(DolangError::Runtime(
            format!("cannot call method '{}' on null", method)
        )),
    }
}

/// 可变方法分发（仅 List 和 Map 需要）
pub fn dispatch_mut(
    receiver: &mut DolangValue,
    method: &str,
    args: &[DolangValue],
) -> Result<DolangValue, DolangError> {
    match receiver {
        DolangValue::List(_) => list::call_mut(receiver, method, args),
        DolangValue::Map(_)  => map::call_mut(receiver, method, args),
        _ => Err(DolangError::Runtime(
            format!("'{}' does not support mutable method '{}'", receiver.type_name(), method)
        )),
    }
}
```

#### 步骤 2.5 — 更新 `eval.rs` 方法调用求值

```rust
Expr::MethodCall { object, method, args } => {
    let evaluated_args: Vec<DolangValue> = args
        .iter()
        .map(|a| self.eval_expr(a))
        .collect::<Result<Vec<_>, _>>()?;

    if builtins::is_mutating(&method) {
        // 可变方法：需要从环境中获取可变引用，就地修改
        let receiver = self.env.get_mut(object)?;
        builtins::dispatch_mut(receiver, &method, &evaluated_args)
    } else {
        // 不可变方法：普通求值即可
        let receiver = self.eval_expr(object)?;
        builtins::dispatch(&receiver, &method, &evaluated_args)
    }
}
```

#### 步骤 2.6 — 更新 `exec.rs` 适配 `DolangValue`

`exec.rs` 中所有与 `env` 交互的代码均需从 `String` 切换为 `DolangValue`，主要涉及：

- 变量赋值 `env.set(name, value)` — value 类型从 `String` → `DolangValue`
- 条件判断 `$if` — 需要从 `DolangValue` 提取布尔值
- `$>>` 输出语句 — 使用 `Display` trait：`println!("{}", value)`
- `$<<` 输入语句 — 将用户输入 `String` 包装为 `DolangValue::Str`
- 函数定义 `$fn` — 存储为 `DolangValue::Function { ... }`
- 函数调用 — 从 env 取出 `DolangValue::Function`，匹配参数

> **风险提示**：`exec.rs` 的改动量可能与 `eval.rs` 相当，务必在此步骤保持高测试覆盖。
